# Support

Design Jarvis is maintained by its community without a guaranteed response time or service-level agreement.

## Get help

- Use the bug-report template for reproducible defects.
- Use the feature-request template for proposed capabilities or workflow changes.
- Use repository discussions for questions and implementation help when discussions are enabled.
- Include the Design Jarvis version, agent runtime, operating system, minimal reproduction, and sanitized evidence.

Search existing issues before opening a new one. Remove credentials, personal data, private customer information, and proprietary source material from all public reports.

Security vulnerabilities and sensitive conduct reports must use the private channels described in `SECURITY.md` and `CODE_OF_CONDUCT.md`.
