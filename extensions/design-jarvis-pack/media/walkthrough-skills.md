# Use and add skills

Built-in skills load automatically when your agent chat request matches them — just describe the task.

Open the **Skill Packs** panel to see what's installed. To add more, choose **Install Skills from Folder** and pick a skill folder (`SKILL.md`), a skill pack folder (`skill-pack.json`), or a parent folder of several skills.

Reload VS Code if prompted, then open a new agent chat. Use the **sync** icon to pull later edits from your source folder.
