# Getting started

1. Install the Design Jarvis extension package.
2. Run **Design Jarvis: Install for Me** to add the agent and prompt files for the current user.
3. Open a project folder.
4. Run **Design Jarvis: Set Up This Workspace** if you want local skills, starters, memory, and eval support in that folder.
5. Optionally connect Figma when your first canvas task asks for it.
6. Start with the Design Jarvis orchestrator or invoke a focused skill.

Example requests:

- “Turn this requirement into a UX brief and identify the next design decision.”
- “Review this interface for accessibility, content clarity, and design-system fit.”
- “Build an interactive prototype in the current project stack and verify its states.”

Design Jarvis discovers the active design system from the project. It does not require a fixed component library, brand, cloud, or private service.
