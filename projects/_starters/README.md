# Shared starters

These files are vendor-neutral starting points. They are read-only: copy a starter into `projects/<slug>/` before editing it.

| Starter | Purpose |
|---|---|
| `_template.html` | Accessible application shell for HTML prototypes |
| `design-tokens.css` | Neutral semantic tokens and reusable utilities |
| `app-foundation/` | Generic application/workspace prototype foundation |
| `slide-deck/` | Self-contained HTML presentation framework |
| `workflow-diagram/` | Mermaid workflow and state-diagram examples |

Every starter is a baseline, not a prescribed brand. Rebind its semantic tokens and replace sample content with the active project’s design system and domain.
