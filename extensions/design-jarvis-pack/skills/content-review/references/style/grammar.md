# Grammar and Voice

Rules for grammar, voice, and sentence structure per plain-language content guidance.

## Verb Tense

Use present tense for current states and actions.

- ✅ "Windows Update installs important updates automatically."
- ❌ "Windows Update will install important updates."

## Voice

Use active voice. Subject performs the action.

- ✅ "The system saves your settings."
- ❌ "Your settings are saved by the system."

Use passive voice only to:

- Avoid blaming the user in errors
- Emphasize the receiver of action

## Mood

- **Indicative** — For facts: "Style sheets are powerful tools."
- **Imperative** — For instructions: "Enter a file name, then save."
- **Avoid subjunctive** — Rephrase "We recommend that you be careful" to "Be careful."

## Pronouns

- Address users as "you"
- Use "we" for the organization
- Use "I/my" only in user choices (checkboxes): "Remember my password"
- Use gender-neutral language: they/them for singular when needed

## Subject-Verb Agreement

- Group of things = singular: "A variety of games is available."
- Things connected by "and" = plural: "Facebook and Instagram are available."
- Things connected by "or" = singular: "Your tablet or phone is all you need."

## Articles

Every countable singular noun needs an article (a, an, the).

- ✅ "Select a workspace"
- ❌ "Select workspace"
- ✅ "The file was saved"
- ❌ "File was saved"

## Common Fixes

| Issue | Fix |
|-------|-----|
| "Settings will be saved" | "The system saves settings" |
| "Click on the button" | "Select the button" |
| "In order to" | "To" |
| "The user should ensure that they" | "Ensure you" |
| "There is a error" | "There is an error" |
| "Setup the workspace" | "Set up the workspace" (verb) |
